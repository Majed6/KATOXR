# KATOXR

An OpenXR API layer for the KATVR C2 Plus.

> This is a personal project and is not actively maintained. Use it at your own
> discretion. Third-party software, including this project, may harm your PC,
> other devices, or accounts.

## Installation

1. Download and install
   [OpenXR API Layers GUI](https://github.com/fredemmott/OpenXR-API-Layers-GUI).
2. Download the latest KATOXR release.
3. Set the OpenXR runtime to **VDXR**.
4. Extract the release, then add `KATOXR.json` to your OpenXR API layers.
